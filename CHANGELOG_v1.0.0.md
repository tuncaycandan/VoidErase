# VoidErase v1.0.0 feature update

Implemented:
1. Safer operation/error handling helpers and protected system paths.
2. Operation summary dialog and SHA-256 verification support classes.
3. Recursive file/folder workflow support is preserved.
4. Settings dialog with deletion confirmation, system-path protection, startup update check, and logging.
5. Existing GitHub updater is preserved.

Note: the existing encryption/deletion implementation remains the source of truth; these additions are designed to integrate without replacing it.
